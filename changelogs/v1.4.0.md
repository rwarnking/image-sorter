# [Changelog v1.4.0](changelogs/v1.4.0.md)

This document contains the most important changes made.

## Features

### Abstract

Events can now be associated with GPS coordinates. Each GPS coordinate is linked to a specific datetime and is represented as a latitude/longitude tuple.

### Details

- Add GUI elements for adding GPS coordinates to an event
- Extend the database schema to store GPS coordinates
- Convert latitude/longitude coordinates to EXIF GPS format
- Add functionality to embed GPS coordinates into images
